git, block by block

This site exists because a friend of mine kept asking if he could "rebase main" when he meant pull. He ships code every day. The git verbs just never came with pictures. So here are the pictures: commits are blocks, and blocks never move. Branches are tags floating above them. Every command plays out step by step. Chain commands together in the sandbox and share a link that replays the whole run.

Built as a companion to Redstone University, a CS course rendered out of Minecraft. Same block language, different subject. If you came from the course and git is still just noises, start here, then head back.

How to read the blocks

Blocks are commits. They never move. Every command that looks like it moves commits is secretly making copies, and the animations show the copies being made.
Tags are refs. A branch is a name pointing at one commit, nothing more. The red one, HEAD, is where you're standing.
The torch is a change in flight: one commit's diff being replayed somewhere new. Rebase, cherry-pick, and revert are all this move.
Dashed means not quite here. Faint sketches are where new commits will land. Ghosts are abandoned commits the reflog still remembers.
Wires point at parents. History is walked backwards. A commit knows where it came from and nothing else.
